# flgr - Feature flag management platform

flgr is a feature flag management platform that allows you to control the availability of features in your application.

## Features

- Create and manage feature flags and environments
- User and profile management
- Enable or disable features for specific users or profiles
- Killswitches to quickly disable a feature in case of issues, notifying consumer applications through Kafka or HTTP requests
- Manage service keys for consumer applications to access feature flags
