# Business Requirements

## Overview

Business requirements describe what the flgr application must do and how well it must do it. They are split into two types:

- **Functional** — the specific behaviors and features flgr must provide to meet user needs (e.g., "users must be able to create a feature flag").
- **Non-functional** — the quality attributes, performance characteristics, and constraints flgr must satisfy (e.g., response time, security, scalability).

Both types share the same template and the same numbering sequence, and are distinguished by the `Type` column in the table below.

## Template

Check [0000-business-requirements-template.md](0000-business-requirements-template.md) for the template to use when creating a new requirement.
