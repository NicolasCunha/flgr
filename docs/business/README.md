# Business

## Overview

This section provides an overview of the business requirements and use cases for the flgr application. For technology and architecture-related information, please refer to the [Architecture](../architecture/README.md) section.

## Business Requirements

Business requirements define what the flgr application must do (functional behavior) and how well it must do it (non-functional quality attributes, such as performance, security, and scalability). Each requirement should be clearly defined, measurable, and testable, so it's possible to verify whether the application meets the expectations of its users.

Requirements are documented individually within the [requirements](requirements) directory, following the template provided in [0000-business-requirements-template.md](requirements/0000-business-requirements-template.md).
